Free, with a wake-up pause.

01

Give your add-on a home.

Start with a Render account and the GitHub repository. Fork the repository if you want your own copy. No programming is required.

  1. In Render, choose New → Web Service.
  2. Select Public Git Repository and paste your fork’s URL, or https://github.com/dev1niscool/stremio-live-tv.
  3. Use the settings below. Choose the Free instance.
  4. Add an environment variable named NODE_VERSION with value 24. Deploy, then open the service’s onrender.com address.

Your full M3U URL may include a username and password. Keep it private.

Click Generate private settings. The form produces a JSON playlist list and a random access key entirely in your browser. It does not upload or save your inputs. Keep the tab open until you have copied the settings.

03

Save them on your host.

In Render, open your service → Environment. Add these two environment values using the copy buttons on the setup page:

KeyValue to paste
PLAYLISTS_JSONThe generated playlist settings
ADDON_TOKENThe generated access key

Select Save, rebuild, and deploy, then wait for the service to become live. Save your access key in a password manager.

The install link is private, too.

Anyone with it can access your channels and retrieve playback URLs containing provider credentials. Do not publish it, your environment values, or your M3U links in GitHub, issues, or screenshots. The hosting service receives playlist credentials; your Stremio player receives stream URLs.

04

Make it part of Stremio.

  1. Return to your service URL and paste your access key under Connect to Stremio.
  2. Choose Check my playlists. Review live-channel and exclusion counts for every source.
  3. Click Install in Stremio. If the app does not open, copy the install URL and paste it into Stremio’s Add-ons screen.
  4. Open Discover, select Live TV, then select the playlist you want. The required All channels filter loads its channels.

These lists have a required Discover filter, which keeps them off Home. They intentionally do not participate in global search. Current Stremio core/web support custom types; individual TV/mobile versions may present them differently.

To change sources later, edit PLAYLISTS_JSON and redeploy. Keep your access key and source IDs unchanged. Reinstall if Stremio caches old source names after adding or removing playlists.

KEEP THE CHANNELS, SKIP THE VOD

A cautious live-only filter.

The service rejects entries with movie, series, recording or other on-demand signals. It also excludes uncertain entries: an .m3u8 URL or a duration of -1 alone does not establish that a stream is live.

If real channels are missing, expand Live channel filtering below the source. Enter the exact live group names, one per line, under Confirmed live groups. This both confirms live intent and limits that playlist to those groups. Use Ungrouped for entries without a group.

Movies and series with clear VOD signals still remain blocked. A mislabeled provider cannot be classified perfectly, and conservative matching can exclude movie-themed live groups. Check your actual playlists before relying on the results.

WHEN SOMETHING NEEDS ATTENTION

A few things to check.

Stremio times out after the service has been idle

Open your Render service URL, let it wake for about a minute, then retry Stremio. Free services sleep after 15 minutes without inbound requests. There is no background keep-alive or paid upgrade in this project.

A playlist has zero channels

Check the setup page’s counts. If entries are unclassified, confirm exact live group names. If all are VOD, inspect your provider’s list. A single HLS playback manifest is not an M3U channel list.

The playlist loads locally but fails on Render

Check your URL and credentials in Environment. Some providers restrict datacenter IPs, locations, or simultaneous connections. Playlist requests have a 20-second timeout and a 25 MiB limit. Local/private-network playlist addresses are intentionally blocked.

Channels appear, but playback fails

Your player connects directly to the IPTV provider. Browser CORS, unsupported codecs, HTTP streams, provider headers and account restrictions can prevent playback. Try current Stremio Desktop/Android TV or a compatible external player. This service does not transcode or proxy video.

Where are Hugging Face and Fly.io?

Older guides call them free. Hugging Face currently requires a paid plan to create Docker Spaces; Fly.io provides a limited trial rather than an ongoing free tier. Render is the default here. See the Hugging Face policy and Fly.io policy.

SMALL SERVICE. OPEN SOURCE.

Run it your way.

Node.js 24, no third-party runtime dependencies, one container if you want it. The source includes parser, protocol, privacy and network tests, a Dockerfile, a Render Blueprint, and GitHub Pages publishing.

git clone https://github.com/dev1niscool/stremio-live-tv.git
cd stremio-live-tv
cp .env.example .env
npm start
# Open http://localhost:7860
# Add private settings to .env, then restart.
npm test

For advanced headers, deployment variables, filtering rules and Docker commands, read the README. Publish your fork’s guide through Settings → Pages → GitHub Actions.
